# SEC//INTEL

世界のサイバーセキュリティ・技術・ガジェット情報を自動で集めて日本語に翻訳し、ランキング表示する個人用サイトです。
GitHub Actions が3時間ごとに情報を集めてサイトを作り直し、GitHub Pages で公開します。毎朝 8:00 には重要ニュースのトップ3を LINE に送ります。

## ページ構成（左上の ≡ メニューから切り替え）

- **ホーム**: 統計、各ランキングの上位3件、直近のイベント、最新の受信ログ
- **重要ニュース**: サイバー攻撃・脆弱性・情報漏えいを「重要度」順に表示
- **技術ニュース**: 攻撃手法の研究・防御技術・ツールを「注目度」順に表示
- **ガジェットニュース**: スマホ・PC・オーディオなどを「注目度」順に表示
- **イベント情報**: 「愛知・東海エリア」と「全国の大規模・重要イベント」に分けて表示

## 公開までの手順（最初の1回だけ）

### 1. GitHub にアップロードする

- リポジトリ: <https://github.com/waturu1925/cybersecurity_news>（Public）
- 無料で GitHub Pages を使うには Public（公開）にする必要があります。サイトの URL を知っていれば誰でも閲覧できる状態になります（検索エンジンには載らない設定にしています）

### 2. GitHub Pages を有効にする

1. リポジトリの「Settings」→ 左メニュー「Pages」
2. 「Build and deployment」の Source を **GitHub Actions** にする
3. 「Actions」タブ →「update」→「Run workflow」で初回の更新を実行（5分ほど）
4. 完了すると <https://waturu1925.github.io/cybersecurity_news/> でサイトが見られます

### 3. LINE 通知を設定する

1. <https://developers.line.biz/console/> に LINE アカウントでログイン
2. 「プロバイダー」を作成 →「Messaging API」チャネルを作成（LINE 公式アカウントも同時に作られます）
3. チャネルの「Messaging API設定」タブで
   - QR コードを読み取り、作った公式アカウントを **友だち追加**
   - 「チャネルアクセストークン（長期）」を **発行** してコピー
4. GitHub のリポジトリ「Settings」→「Secrets and variables」→「Actions」→「New repository secret」で登録
   - `LINE_CHANNEL_ACCESS_TOKEN` … 3 のトークン
   - `LINE_USER_ID` …（任意）「チャネル基本設定」タブの一番下にある **あなたのユーザーID**（U から始まる文字列）。未登録の場合は公式アカウントの友だち全員への一斉送信になります
5. 「Actions」→「update」→「Run workflow」で **LINE にも通知を送る** にチェックして実行すると、テスト通知が届きます

LINE の無料プランは月200通まで送れます（この仕組みは1日1通なので十分です）。

### 4.（任意）connpass の勉強会も表示する

connpass の API キー（<https://connpass.com/about/api/> から申請）を `CONNPASS_API_KEY` として同じくシークレットに登録すると、東海エリアの勉強会がより多く表示されます。

## スマホで使う

スマホのブラウザでサイトを開き、「ホーム画面に追加」するとアプリのように起動できます。

- iPhone（Safari）: 共有ボタン →「ホーム画面に追加」
- Android（Chrome）: 右上の︙ →「ホーム画面に追加」

## 手元の PC で確認する

`start.bat` をダブルクリックすると、情報を集めてサイトを作り、<http://127.0.0.1:8000/> で表示します（終了は黒い画面で `Ctrl + C`）。

## カスタマイズ

- 情報源・採点ルール・レベル名: `config.py` の `CHANNELS`
- 主要イベントの一覧: `curated_events.py`（日程が発表されたら追記。終了したイベントは自動で非表示）
- 通知時刻・更新間隔: `.github/workflows/update.yml` の `cron`（時刻は UTC。日本時間 − 9時間）

## スコアの決め方（0〜100）

- **基本スコア**: 記事中のキーワードや情報源の信頼度で加点（ルールは `config.py` の `keyword_rules`）
- **新しさ補正**: 24時間以内 ×1.0 / 3日以内 ×0.95 / 1週間以内 ×0.85 / 30日以内 ×0.7 / それより前 ×0.6
- **複数ソース加点**: 同じ CVE を複数の情報源が報じていれば最大 +15
